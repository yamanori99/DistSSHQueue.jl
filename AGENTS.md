# Agents

Users run `julia -m DistSSHKit`. This repository is DistSSHQueue.

Library `teardown` deletes only when `confirm_paths` matches every existing target. Use the CLI and `--confirm-path`.

Agents must not pass `-y`, `--yes`, or set `DISTSSHKIT_YES` for `teardown`. Use `--confirm-path` with the path the command printed.

Ask before editing `.coderabbit.yaml` or `.github/`.
