DistSSHQueue.jl

Leave jobs on a queue host. They run one at a time. You can submit a job, check its status, fetch a finished leaf, and cancel. Supported on macOS, Linux, and WSL2 Ubuntu (not native Windows).

The longer guide is the DistSSHKit manual.

Install

pkg> add DistSSHQueue

Julia 1.13+. The queue host and each client need ssh and rsync. A client uses them for qhost: submit and fetch. Git deploys also need git.

Commands

The command is julia -m DistSSHQueue.

julia -m DistSSHQueue qhost:HOST submit go SCRIPT.jl
julia -m DistSSHQueue status
julia -m DistSSHQueue fetch ID
using DistSSHQueue
q = Queue(; store=default_store_path(), follow_config=true)
id = submit!(q, "SCRIPT.jl", "child:host1:4"; kind=:go)
