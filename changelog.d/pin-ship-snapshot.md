- Per-job `setup!(:ship_tree)` keeps DistSSHRun `result_remote_run_id` on that job (`snapshot`, with the child host set, project, and remote). The same id is passed as `snapshot=` to `:instantiate`, `:check`, and detached `execute!`. A later ship on another job does not retarget this one. A successful ship without that id is an error; there is no fallback to latest. Requires DistSSHRun PR 357. Tests pin that commit SHA (`b9580ae1513a26352dac0f5f5accacfa39a60a43`); GitHub still serves a PR commit by SHA after a squash merge. Restoring `[sources] rev = "main"` after Run merges is a later step, not this change.
